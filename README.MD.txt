Scramble Word Search - Web Application

A fully responsive, interactive single-page word search game designed for desktop and mobile browsers. Players swipe or drag across a dynamic grid to find hidden target words, while unselected letters shuffle every 30 seconds to increase difficulty.

Gameplay Features
**Dynamic Grid:** Generated with automated diagonal, horizontal, and vertical word placements.
**Scramble Mechanic:** Leftover grid letters completely shuffle every 30 seconds to keep gameplay fast-paced.
**Responsive Layout:** Perfectly aligned and symmetrical split-screen view on desktop devices, shifting seamlessly to a stacked view for mobile phones.

Built With
* Core HTML5 Layout
* Embedded CSS3 Grid and Flexbox Structuring
* Pure Vanilla JavaScript (No external frameworks or dependencies)
